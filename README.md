# Internet of Bugs

Moving to China has introduced a unique set of challenges related to internet access, network restrictions, and firewall policies. These challenges can be particularly frustrating for software developers who rely on fast, reliable access to package registries, documentation, APIs, and other online resources.

**Internet of Bugs** is a collection of practical solutions, workarounds, and troubleshooting guides for resolving these connectivity issues.

From configuring alternative package registry mirrors to troubleshooting network requests and exploring VPN-based solutions, this repository documents the problems I encounter and the approaches that help solve them.

The goal is simple: **document what works, share practical solutions, and make life easier for developers facing similar internet connectivity challenges in China.**
